### 2026-08-14 触摸8191排查结论（已定位）

> 排查方式：arduino-cli 编译上传诊断程序 + 串口实测（诊断代码在 `03_ESP32代码\触摸调试\touch_bus_diag\`）

| 排查项 | 结论 |
|--------|------|
| 恒定8191的直接原因 | **SD卡模块MISO霸占SPI总线**：带电平转换模块的74HC125缓冲芯片OE焊死GND，SD卡空闲时把MISO钉在高电平 → XPT2046读出来全是1（8191）。拔掉SD模块MISO线后触摸立即恢复正常 |
| TOUCH_CS配置 | `User_Setup.h`中`TOUCH_CS 21`必须保持启用（无`//`），曾被人为加注释，已纠正 |
| SPI触摸频率 | 2.5MHz → **1MHz**（`SPI_TOUCH_FREQUENCY`），低频率下读取更稳，已写入User_Setup.h |
| XPT2046芯片/触摸屏 | ✅ 完全正常：TFT_eSPI `getTouch` 返回 `ok=1`，坐标/压力读数正常（诊断v8实测） |
| CS链路（GPIO21→CS2） | ✅ 正常（诊断v7对照实验：选中/不选中读数不同） |

**遗留问题**：SD卡模块与触摸不能共存（MISO干扰）。解决方案（任选）：
1. 换3.3V直连、无电平转换的SD卡模块（¥5左右，无74HC125即无干扰）——推荐
2. 改造现有模块：把74HC125的OE脚从GND焊开，改接SD_CS（选中SD时才驱动MISO）

## 四、SPI总线架构

SPI总线三设备共享，各自CS片选分离：

```
ESP32                    SPI总线
├── GPIO18(CLK) ────────┬── 屏幕 CLK
│                        ├── 触摸 CLK
│                        └── SD卡 CLK
├── GPIO23(MOSI) ───────┬── 屏幕 MOSI
│                        ├── 触摸 MOSI
│                        └── SD卡 MOSI
├── GPIO19(MISO) ───────┬── 屏幕 MISO
│                        ├── 触摸 MISO
│                        └── SD卡 MISO
├── GPIO15(CS) ─────────── 屏幕 CS1
├── GPIO21(CS) ─────────── 触摸 CS2
└── GPIO14(CS) ─────────── SD卡 SD_CS
```

原理：CLK/MOSI/MISO广播共用，CS一人一根，ESP32拉低谁的CS谁应答，其余设备MISO高阻装死。
SPI频率：屏幕40MHz（实测正常）；SD卡400kHz~4MHz；触摸**1MHz**（8-14从2.5MHz降频，读取更稳）。

⚠️ 多设备共总线时，代码里要把不用的CS全部pinMode+拉高，避免悬空CS被误选中干扰总线。

## 十一、技术注意事项与踩坑记录

### 1. DC引脚（最关键的坑）
白屏根因：DC写GPIO2，实际接GPIO5。解决：`#define TFT_DC 5`。

### 2. Arduino项目名必须英文
文件夹名 = .ino文件名，必须纯英文。

### 3. TFT_eSPI库安装（代理坏了）
手动curl下载zip + Python解压到libraries目录。

### 4. ESP32 Core升级（大文件下载卡住）
用ghfast.top镜像加速，下载后放staging目录跳过IDE下载。

### 5. TFT_eSPI API注意
- 无`readID()` → 用`readcommand32(0x04)`
- setup_t字段带`pin_tft_`前缀，无`pin_tft_bl`，背光手动控制GPIO25

### 6. 串口占用（WindowsError 31）
关串口监视器→拔插USB→重选端口→波特率115200。
IDE 2.x串口监视器上传后经常不重连：上传完按RST键或重开监视器。

### 7. MQ-135注意事项
AO必须10k+20k分压到3.3V；预热24-48小时；功耗大建议间歇采样。

### 8. 3V3接口只有一个
多设备3.3V用洞洞板并联。

### 9. SD卡初始化失败（2026-08-07新增，已解决）
- 现象：SD.begin重试5次全失败，换CS引脚/降速/拔屏幕全无效
- 根因：**MicroSD卡没插到底，卡座接触不良**
- 教训：插卡按到底听到咔哒声；排查硬件时"重新插拔"是成本最低的必杀技

### 10. 触摸无应答8191（2026-08-07新增，**2026-08-14已解决**）
- 现象：getTouchRaw读数恒定x=8191 y=8191（全1）= XPT2046未被选中
- 已排除：换CS2杜邦线无效
