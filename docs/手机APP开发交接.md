## 一、项目一句话

"啾啾"是一个桌面摆件式智能聊天机器人：以ESP32为主控，带2.8寸触摸屏、语音播报、温湿度/空气质量传感器，能连WiFi与云端大模型对话。**手机APP是它的远程搭档**：发消息、看数据、配网络、管文案。

## 二、系统三端架构

```
┌─────────────┐      WiFi/蓝牙      ┌──────────────┐
│   手机APP    │ ◄────────────────► │  啾啾(ESP32)  │
│ (本交接内容) │   HTTP/JSON + BLE   │  ·ILI9341触屏 │
└─────────────┘                     │  ·SYN6288语音 │
                                    │  ·DHT11/MQ135 │
                                    │  ·SD卡存储    │
                                    └──────┬───────┘
                                           │ WiFi直连
                                    ┌──────▼───────┐
                                    │   云端服务    │
                                    │ ASR/大模型API │
                                    │ (ESP32直连,   │
                                    │  APP不参与)   │
                                    └──────────────┘
```

**关键边界：语音对话链路（麦克风→云端→TTS播报）由ESP32直连云端完成，APP不参与。** APP只负责人↔啾啾的远程交互。

## 三、啾啾本体能力摘要（APP开发者需要知道的）

| 能力 | 说明 |
|------|------|
| 主控 | ESP32 NodeMCU-32S，自带WiFi + 蓝牙（支持BLE和经典蓝牙SPP） |
| 屏幕 | 320×240 横屏，可显示文字、图片 |
| 语音输出 | SYN6288中文TTS模块，ESP32收到文字即可播报 |
| 传感器 | DHT11温湿度、MQ-135空气质量（ADC数值） |
| 存储 | SD卡（字体/图片/鼓励语库） |
| 供电 | 开发期USB，成品18650电池（续航有限，通信设计注意省电） |

## 四、APP功能需求

### 交付形态
- **安卓APK**，可直接安装，minSdkVersion 建议 26（Android 8.0）以上
- 界面风格：可爱 + 简洁，符合"桌面宠物伴侣"定位

### 核心功能（四项，均为必需）

| # | 功能 | 说明 |
|---|------|------|
| 1 | **远程发消息到屏幕** | APP输入文字 → 啾啾屏幕显示，并可选"同时语音播报"开关 |
| 2 | **查看传感器数据** | APP实时查看温度、湿度、空气质量数值，可手动刷新 |
| 3 | **WiFi配网** | 啾啾未联网时，通过蓝牙把WiFi名称+密码发给啾啾；配网成功后自动切换到WiFi通信 |
| 4 | **鼓励语管理** | 查看啾啾SD卡里的鼓励语列表，可添加、删除单条 |

### 扩展性要求（重要）

- 通信协议带**版本号字段**，所有消息JSON格式，便于后期新增指令类型
- 指令采用 `cmd` 字段分发，新增功能只需新增cmd值，不改框架
- 代码结构模块化：通信层 / UI层 / 数据层分离，后期可加新页面

## 五、通信协议（对接标准，双方必须遵守）

### 5.1 通道策略

| 场景 | 通道 | 说明 |
|------|------|------|
| 同一WiFi下 | **HTTP局域网** | ESP32开HTTP服务，APP直接请求 |
| 未配网/无WiFi | **蓝牙BLE** | 仅用于配网和兜底控制，指令与HTTP同构 |

### 5.2 HTTP接口（局域网，ESP32为服务器）

统一约定：请求和响应均为JSON，含 `"ver": 1` 版本号。

| 接口 | 方法 | 请求体 | 响应体 | 对应功能 |
|------|------|--------|--------|---------|
| `/api/message` | POST | `{ver, cmd:"msg", text:"...", tts:true}` | `{ok:true}` | 发消息到屏幕，tts=true时语音播报 |
| `/api/sensor` | GET | — | `{ver, temp:25.6, humi:48, air:1234}` | 读传感器（air为MQ-135原始ADC值） |
| `/api/phrase/list` | GET | — | `{ver, list:["...","..."]}` | 鼓励语列表 |
| `/api/phrase/add` | POST | `{ver, cmd:"add", text:"..."}` | `{ok:true}` | 添加鼓励语 |
| `/api/phrase/del` | POST | `{ver, cmd:"del", index:3}` | `{ok:true}` | 按序号删除 |
| `/api/status` | GET | — | `{ver, ip, wifi, sd, battery}` | 设备状态心跳 |

### 5.3 蓝牙配网（BLE）

- ESP32作为BLE外围设备，服务UUID自定义即可（文档中声明，APP硬编码）
- 特征值写入JSON：`{ver, cmd:"wifi", ssid:"...", pwd:"..."}`
- ESP32回写notify：`{ok:true, ip:"192.168.x.x"}` → APP拿到IP后切换HTTP通道

### 5.4 错误处理

- 所有接口异常统一返回 `{ok:false, err:"原因描述"}`
- APP侧超时建议：HTTP 3秒，BLE写入5秒
